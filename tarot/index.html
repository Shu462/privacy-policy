Pastel Tarot プライバシーポリシー

対象アプリ: Pastel Tarot（スマートフォン向けタロット占いアプリ / Android・iOS）

最終改定日: 2026-05-05

発行者: kosuga shun

連絡先: mieruyorara5@gmail.com

本ページは、スマートフォン向けタロット占いアプリ「Pastel Tarot」（以下「本アプリ」）におけるプライバシーポリシーです。 本アプリは、利用者のプライバシーを尊重し、以下の方針で情報を取り扱います。

1. 取得する情報

1-1. 匿名認証ID

Supabase 匿名認証によって自動付与される一意の識別子です。氏名・メールアドレス・電話番号等の個人情報は取得しません。

1-2. 占い履歴

占い結果（カード組み合わせ・スプレッド種別・任意で入力された質問文）を、原則として端末内 (AsyncStorage) に保存します。匿名認証が確立している場合に限り、Supabase の readings テーブルにバックアップ目的で同期されます。

1-3. 課金情報

「Pastel Tarot プラス」を購入された場合、RevenueCat および各ストア（Apple / Google Play）が課金情報を処理します。本アプリは決済カード番号や請求先住所を取得しません。

1-4. 広告 ID

無料利用時、Google AdMob が広告 ID 等を処理します。利用者は端末設定からオプトアウトが可能です。プレミアム購入後は広告が表示されないため、これらの送信もありません。

2. 情報の利用目的

  • 占い履歴の保存および機種変更時の引き継ぎ
  • アプリ内課金の処理および権限の付与
  • 無料利用時の広告配信

3. 第三者への提供

提供先提供内容目的
Supabase Inc.匿名認証ID・占い履歴バックエンド・履歴クラウド保存
RevenueCat, Inc.匿名認証ID・購入情報買切購入の権限管理
Apple / Google Play課金情報アプリ内課金処理
Google AdMob広告 ID 等広告配信（無料利用時のみ）

各社のプライバシーポリシー:

  • Supabase: https://supabase.com/privacy
  • RevenueCat: https://www.revenuecat.com/privacy
  • Apple: https://www.apple.com/legal/privacy/
  • AdMob: https://policies.google.com/technologies/ads

4. データの保管期間

端末内データ: 利用者が削除するまで

クラウドデータ: 利用者が「履歴をすべて削除」を実行するか、アプリのアカウントを削除するまで

5. データの削除リクエスト

設定画面の「履歴をすべて削除」を実行すると、端末内およびクラウド上の占い履歴が削除されます。アカウント自体の削除をご希望の場合、上記連絡先までご連絡ください。

6. 子どもの利用

本アプリは13歳未満の利用を想定していません。13歳未満の方は保護者の同意を得てご利用ください。
